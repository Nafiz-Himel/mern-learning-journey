## 🌟 About This Repository

This repository serves as a **complete learning roadmap** and portfolio of my progress in web development. It contains organized code, projects, and notes from beginner level (HTML) all the way to building production-ready full-stack applications using the **MERN Stack**.

### Learning Path
- **01-html** — HTML5 Fundamentals & Semantic Markup
- **02-CSS** — Modern CSS, Flexbox, Grid, Responsive Design & Animations
- **03-javascript** — Vanilla JavaScript, DOM Manipulation, ES6+, Async Programming
- **04-react** — React.js (Hooks, Context API, Router, State Management, etc.)
- **05-express.js** — Backend Development with Node.js & Express
